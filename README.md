# Portfólio de Victor Garrido

Este pacote contém o site completo para GitHub Pages, com seis vídeos enviados por Victor: cinco verticais e um horizontal. As imagens de capa foram extraídas dos próprios vídeos. Os quatro Reels foram otimizados para reprodução na web, mantendo o enquadramento vertical; os dois vídeos do YouTube foram preparados para iniciar a reprodução durante o carregamento.

## Publicar

1. Extraia este ZIP no computador. O `index.html` deve ficar no mesmo nível das pastas `imagens`, `capas` e `videos`.
2. No repositório `SEU-USUARIO.github.io`, envie **todo esse conteúdo** para a raiz da branch `main`.
3. Como `videos/youtube-longo.mp4` tem cerca de 76 MiB, use GitHub Desktop ou Git no computador para enviar o projeto completo. O envio de arquivos grandes pelo navegador do GitHub tem um limite menor.
4. Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main** e pasta **/(root)**.
5. Abra `https://SEU-USUARIO.github.io` e teste os seis projetos.

`SEU-USUARIO` é o identificador que aparece no endereço do perfil GitHub, sem espaços; o nome público do site é Victor Garrido.

## Conteúdo

| Projeto no site | Arquivo | Formato |
| --- | --- | --- |
| Reel 01–04 | `videos/reel-01.mp4` a `videos/reel-04.mp4` | Vertical, 720 × 1280 |
| Short para YouTube | `videos/youtube-short.mp4` | Vertical, 720 × 1280 |
| Vídeo para YouTube | `videos/youtube-longo.mp4` | Horizontal, 1280 × 720 |

O player pausa e reproduz, permite buscar um trecho na barra de tempo, avançar ou voltar 10 segundos e entrar em tela cheia. Ele detecta a orientação de cada arquivo. O e-mail e Instagram já estão no site. Os títulos são descritivos porque não foram fornecidos títulos de publicação; você pode substituí-los no `index.html`.
